## Хостинг

- Сайт сейчас на **GitHub Pages**, а стандарт — Vercel. Переезд требует смены DNS, это
  запрещено без согласия, поэтому: сделан полный `vercel.json` (редиректы, заголовки, кеш,
  noindex для `*.vercel.app`), а GitHub Pages продолжает работать. Инструкция переезда — в DEPLOY.md.
- Деплой на GitHub Pages теперь только из `main` (раньше ещё из `claude/brave-shannon-o9pdvr`),
  и перед публикацией запускается `check:seo`. Иначе процесс «ветка → PR → main» не имеет смысла.
- Папка ассетов осталась `/assets/` (а не `/_astro/`), как было в проекте; кеш-заголовок настроен на неё.
- `/index.html → /` и `www`/`http` на GitHub Pages редиректятся только средствами самого Pages;
  монитор помечает это предупреждением, а на Vercel — ошибкой.

## SEO и разметка

- Страницы перенесены в `src/views/*` + маршруты `src/pages/[...lang]/*`: одна вёрстка на два языка.
- Все страницы, их title/description, даты и тексты для llms.txt описаны в одном месте —
  `src/lib/routes.ts`. Из него же строятся sitemap, llms.txt и OG-обложки.
- `lastmod`: у сайтов — поле `updated` в `tools.json` (поставлено 2026-11-13, день перевода
  на русский), у категорий — `updated` в `categories.json`, у остальных страниц — `PAGE_UPDATED`
  в `routes.ts`, у главной и списков — самая свежая дата из их содержимого.
- Sitemap свой (эндпоинты Astro), а не `@astrojs/sitemap`: так `lastmod` берётся из данных.
- Длинные title обрезаются по слову с «…»; « · Atlas» добавляется, только если влезает в 60 символов.
- Страница сайта из каталога размечена как `ItemPage` + `SoftwareApplication`/`WebApplication`
  (WebApplication — если работает только в браузере). Без `offers` и рейтингов: цен у нас нет.
- Person: тот же `@id` (`https://ehroz.pro/#person`), что и на ehroz.pro, — поисковики свяжут сайты.
- Новая страница «Контакты» (`/contact/`, `/en/contact/`); «Обо мне» — блок «Кто делает Atlas»
  на странице «О проекте» (отдельная страница об авторе уже есть на ehroz.pro).
- 404 одна на сайт (так работают и GitHub Pages, и Vercel), текст на двух языках.
- OG-обложки: satori + resvg; шрифт Medeo Sans переведён в статические TTF (`src/assets/og/`),
  потому что satori не читает woff2 и вариативные шрифты.
- IndexNow-ключ сгенерирован новый: `3131d3161e6c162efaf7ae2e845b59ce`.
- `ALLOW_AI_TRAINING = true` — как на ehroz.pro.

## Аналитика

- Vercel Analytics рендерится только при `VERCEL_ENV=production` и дополнительно отбрасывает
  события не с `atlas.ehroz.pro` (production-деплой доступен и по адресу `*.vercel.app`).
- События, для которых нет элементов, убраны: `download_click`, `open_app_click`, `order_click`,
  `read_complete`. Кнопка «Открыть сайт» на странице инструмента шлёт `outbound_click`
  (с параметром `tool`), форма «Предложить сайт» — `contact_click` (`method: submit_form`).
- Согласие хранится в `localStorage` под ключом `atlas:consent`. «Настройки cookies» сбрасывают
  его; если счётчики уже загружены, страница перезагружается, чтобы их выгрузить.

## Безопасность

- В CSP `style-src 'unsafe-inline'`: в вёрстке много `style="…"`, а хешировать атрибуты нельзя.
- Убран единственный inline-обработчик (`onsubmit` в поиске), иначе его заблокировала бы CSP.
- `npm audit`: 2 moderate — `fflate` внутри `satori` (зацикливание на битых ZIP64). satori работает
  только при сборке и ZIP не распаковывает; «исправление» `npm audit fix --force` откатывает satori
  на старую мажорную версию — не делал. Astro обновлён в пределах патча (7.4.11 → 7.4.12).
