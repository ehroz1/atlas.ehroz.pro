# Админка

Адрес: **https://atlas.ehroz.pro/admin/** (страница закрыта от поисковиков).

Здесь можно добавить сайт в каталог, изменить его или удалить. Сервер не нужен:
админка сохраняет изменения коммитом прямо в `main` этого репозитория, после чего
GitHub Actions пересобирает и публикует сайт — обычно за 2–4 минуты.

## Первый вход (один раз)

1. Откройте https://github.com/settings/personal-access-tokens/new
2. **Token name** — например, `atlas admin`. **Expiration** — на ваш выбор.
3. **Repository access** → *Only select repositories* → `ehroz1/atlas.ehroz.pro`.
4. **Permissions → Repository permissions → Contents: Read and write**. Больше ничего не нужно.
5. **Generate token**, скопируйте его и вставьте на странице `/admin/`.

Токен хранится только в вашем браузере (галочка «Запомнить»). «Выйти» его стирает.
Если токен утёк — удалите его на GitHub в Settings → Developer settings → Personal access tokens.

## Что умеет

- **Добавить сайт**: адрес, название, категория, цена, платформы, теги, короткое
  описание и описание на русском и английском, альтернативы. ID (адрес страницы
  `/tools/<id>/`) подставляется из названия.
- **Скриншот** можно загрузить свой (обрежется до 16:10, 1440×900). Если не загружать —
  при публикации workflow снимет его сам (`npm run shots`) и закоммитит в
  `src/assets/shots/`. Сайты за защитой от ботов снять не получится — карточка
  покажет домен; тогда загрузите картинку вручную.
- **Изменить** любое поле. Если поменялся текст, дата «изменено» обновится сама.
  Галочка «Переснять скриншот» удалит старый, и при публикации снимется новый.
- **Удалить**: убирает сайт из `tools.json`, из групп в `alternatives.json` и его скриншот.

Каждое действие — отдельный коммит вида `Add … (admin)` / `Update …` / `Remove …`,
так что любое изменение можно откатить через `git revert` или в истории на GitHub.

## Как устроено

- `public/admin/` — статическая страница (`index.html`, `admin.js`, `admin.css`),
  общается только с `api.github.com`.
- Перед каждым сохранением файлы читаются заново из `main`, так что правки, сделанные
  в другом месте, не затираются.
- `.github/workflows/deploy.yml` перед сборкой снимает недостающие скриншоты для сайтов,
  добавленных за последние 14 дней, и коммитит их обратно.
- Категории в админке не редактируются — они в `src/data/categories.json`.
