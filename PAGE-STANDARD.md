# Стандарт страницы

Как добавить страницу, чтобы она сразу была в sitemap, llms.txt, с OG-обложкой и микроразметкой.

## Новый сайт в каталог

1. Запись в `src/data/tools.json`: `summary` и `description` на `ru` и `en`, `added` и `updated`
   (дата последнего изменения текста — она идёт в sitemap `lastmod`).
2. Скриншот: `npm run shots -- <id>`.
3. `npm run build && npm run check:seo`.

Страница `/tool/<id>/` и `/en/tool/<id>/`, обложка, sitemap и llms.txt появятся сами.
Поменяли текст — обновите `updated`.

## Новая обычная страница

1. Тексты — в `src/i18n/ru.ts` и `src/i18n/en.ts` (ключи `<page>.title`, `<page>.description`, `<page>.h1`…).
2. Запись в `src/lib/routes.ts` (через `simple(...)` или свою) + дата в `PAGE_UPDATED`.
3. Вид страницы — `src/views/<Page>.astro`, принимает `lang`, оборачивается в
   `<Base lang entry crumbs …>`.
4. Маршрут — `src/pages/[...lang]/<page>.astro` (5 строк, как у соседей).
5. Ссылка на неё из шапки/подвала или других страниц (иначе `check:seo` найдёт сироту).

## Чек-лист

- [ ] Ровно один `h1`; заголовки без скачков (h1 → h2 → h3).
- [ ] Первый абзац под h1 объясняет суть страницы.
- [ ] title ≤ 60 символов, description 50–160, оба уникальны (проверяет `check:seo`).
- [ ] Есть на обоих языках; hreflang и переключатель языка работают сами.
- [ ] Хлебные крошки (`crumbs`) совпадают с иерархией; в JSON-LD они попадут сами.
- [ ] Тип страницы в `schema.ts` (`PAGE_TYPE`) подходит; новые сущности — только с реальными данными.
- [ ] Ссылки внутри сайта — через `u('/path', lang)` (слеш в конце, префикс языка, base).
- [ ] Картинки через `<Image>` из `astro:assets` (размеры), осмысленный `alt` или `alt=""` для декоративных.
- [ ] Никаких inline-обработчиков (`onclick=`) — их заблокирует CSP. Скрипты — `<script>` в компоненте.
- [ ] Внешние скрипты/домены — только через `integrations/csp.mjs`.
- [ ] Видимый фокус, работа с клавиатуры, на 375 px нет горизонтальной прокрутки.
- [ ] `npm run build && npm run check:seo && npm run check:a11y` — зелёные.
